How the calculator works

    

      
Each cloud hands out pod addresses differently, so the same "50 nodes" costs a different amount of address space on each. The calculator applies the published rule for the cloud you pick, shows the arithmetic, and links every rule to the page it came from. The EKS instance table (ENIs and IPv4 addresses per ENI for __EKS_DATA_COUNT__ instance types) is generated from the file the EKS AMI itself uses, commit __EKS_DATA_COMMIT__ of __EKS_DATA_DATE__.

What it does not do

      
It does not model security groups for pods (branch ENIs), GKE multi-Pod CIDR, or AKS static block allocation. Those change the arithmetic; the per-cloud sources above describe each one. The numbers are planning maximums: real clusters also lose addresses to load balancers, endpoints and node replacements.


      
Frequently asked questions

      

        
How many pods can run on an m5.large in EKS?
29 with the default VPC CNI: 3 ENIs × (10 IPs − 1) + 2. With prefix delegation the formula gives 434, and the managed node group cap of 110 applies.

        
How many pods can an EKS node run with custom networking?
Fewer than without it: the primary ENI no longer serves pods, so max pods is (ENIs − 1) × (IPs per ENI − 1) + 2. An m5.large drops from 29 to 20 and an m5.2xlarge from 58 to 44; with prefix delegation on top the formula gives 290 for an m5.large and the managed node group cap of 110 applies.

        
How many pods can a Windows node run on EKS?
Windows nodes keep a single ENI, so the available Pod addresses are IPs per ENI minus one: 9 on an m5.large, 14 on an m5.2xlarge. Windows prefix delegation multiplies that by 16 (144 and 224), and kubelet's default max-pods of 110 then applies.

        
Does an IPv6 EKS cluster still run out of IP addresses?
Not for Pods. Each node gets a /80 IPv6 prefix, so max pods follows the prefix formula and the managed node group cap, and the real limit is CPU and memory. The IPv4 subnet only has to hold one address per node plus the control plane. The IP family is fixed when the cluster is created.

        
How many IP addresses does an EKS node consume?
Up to ENIs × IPs per ENI in secondary-IP mode, because the CNI allocates every address of an attached ENI and keeps a spare ENI warm by default. An m5.large can hold 30 VPC addresses; set WARM_IP_TARGET and MINIMUM_IP_TARGET to shrink the warm pool.

        
Why is my EKS subnet out of IP addresses with only 10 nodes?
Because pods, not nodes, take the addresses. Ten m5.2xlarge nodes at 58 pods each can hold 600 addresses, and a /23 has 507 usable. Use a /19 per zone, or turn on prefix delegation.

        
How big should the GKE Pod range be?
One block of /(31 − ⌈log₂ pods per node⌉) per node: 110 pods per node is a /24 per node, so 900 nodes need a /14 secondary range. Reduce max Pods per node to shrink it.

        
Which AKS network plugin uses the fewest VNet addresses?
Azure CNI Overlay: one VNet address per node, pods from a private CIDR. Legacy Azure CNI pre-assigns maxPods addresses per node, so 50 nodes at the default 30 pods take 1,581 VNet addresses.

        
Does the calculator upload anything?
No. The page runs entirely in your browser; the share link stores the inputs in the URL fragment, which browsers do not send to the server.
